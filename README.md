# BMGT 1309 – 2.1.5 The Incomplete Project Charter

An interactive student activity for **BMGT 1309: Introduction to Project Management**.

## Overview

Students review a draft project charter for a fictional *Distribution Center Upgrade* project and evaluate each element using a structured checklist. The activity reinforces understanding of what a complete, well-formed project charter should contain.

## Activity Features

- 📄 **Draft Charter** — the incomplete charter is displayed on-screen for reference
- ✅ **Interactive Checklist** — students mark each of the 8 charter elements as Present and/or Complete, with a free-text notes field for their reasoning
- 📊 **Instant Feedback** — "Check My Answers" scores responses, highlights correct/incorrect rows, and displays a score summary
- 🔑 **Answer Key** — instructor feedback for each element can be revealed on demand
- 🔄 **Reset** — clears all responses to start fresh

## Usage

Open `2.1.5-incomplete-project-charter.html` directly in any modern web browser. No server, installation, or internet connection required.
