2.1.5 – The Incomplete Project Charter

Review the draft project charter below. Then use the checklist to evaluate each element.

📄 Draft Project Charter

Project Title: Distribution Center Upgrade
Project Manager: Sarah Chen
Description: We need to fix the problems in our distribution center. The current system is old and causing issues. We'll implement a new warehouse management system and make improvements to operations.
Budget: Approximately $500,000
Timeline: Start in January, finish sometime in the summer
Stakeholders:
  • CEO
  • Operations Team
  • IT Department

✅ Evaluation Checklist

For each element, mark whether it is Present (included at all) and Complete (sufficient detail). Then add a note explaining your reasoning.

#  Element Present? Complete? Your Notes
1. Project Title & Description
2. Project Objective / Purpose
3. Project Scope (High-Level)
4. Deliverables
5. Schedule Milestones
6. Budget Estimate
7. Project Manager & Authority Level
8. Stakeholders & Sponsor

🔑 Answer Key

Element Present? Complete? Instructor Feedback
1. Project Title & Description Yes No Title is okay, but description is too vague ("fix problems," "make improvements").
2. Project Objective / Purpose No No Doesn't explain WHY the project is being done or what business value will be achieved.
3. Project Scope (High-Level) Yes No Mentions WMS and "improvements" but not specific about what's in or out of scope.
4. Deliverables No No No specific deliverables are listed anywhere in the charter.
5. Schedule Milestones Yes No Very vague ("sometime in summer"); no milestones or intermediate dates defined.
6. Budget Estimate Yes No Has a number but no breakdown, contingency, or confidence level noted.
7. PM & Authority Level Yes No Names the PM but doesn't define her authority level or decision-making power.
8. Stakeholders & Sponsor Yes No Lists some stakeholders but no project sponsor is identified and the list is incomplete.
